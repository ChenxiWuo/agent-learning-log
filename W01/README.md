## 为什么这一周不能跳

W1 的三个隐形目标，比「跑通 API」重要得多：

1. **建立最小反馈回路**：代码 → 运行 → 看到输出 → 记账。后面 14 周的评测能力，本质就是这个回路放大。
2. **把成本变成本能**：Agent 项目最容易死的地方不是效果，是「跑得起但烧不起」。从第一次调用就开始记账，W10 的成本面板才有数据。
3. **养成「能跑的东西才算数」**：每周产出一个可打开的东西，是这份计划防拖延的核心机制。

## D1 拆解（今天）

1. **跑自检**：`python check_env.py` → 生成 `环境清单.md`，看清哪项缺。
2. **建环境**：`uv sync`（用 pyproject.toml 装依赖，生成 `.venv` 和 `uv.lock`）。
3. **拿 Key**：https://platform.deepseek.com/api_keys（需要注册+充值，最低额度即可，1 元能跑几百次）。
4. **填 .env**：复制 `.env.example` → `.env`，粘贴 key。
5. **首次调用**：`uv run python first_call.py` → 看到回答 + token + 成本，`calls.jsonl` 多一行。
6. **留证据**：把「一句话说明这次调用花了什么」写进 `notes/W01-D1.md`。

## Docker 决策（D5 之前必须定）

当前机器：**Docker 未装，WSL2 未启用**。三条路：

| 方案 | 代价 | 适用 |
|---|---|---|
| A. 装 WSL2 + Docker Desktop（推荐） | `wsl --install` 后重启一次；占盘约 3—5G；Windows 家庭版也可 | W5 部署、W8 沙箱、W13 压测都要 Docker，越早装越省事 |
| B. 云上临时环境（Codespaces/轻量服务器） | 不占本机，但要网络和配置时间 | 本机磁盘紧张、或近期会重装系统 |
| C. 只写 Dockerfile 不跑 | 0 成本，但 D5 验收作废 | 仅在完全赶不上进度时降级 |

我建议 A，安排在周六上午做（重启不影响工作日晚上的学习）。
