## 第 1 步 · Git 收尾（现在就能做完）

你已有名字和邮箱，缺换行符策略和默认分支名。在任意目录开 PowerShell：

```powershell
git config --global core.autocrlf input
git config --global init.defaultBranch main
git config --global --list
```

**为什么设 `core.autocrlf input`**：Windows 编辑器默认写 CRLF，Linux/CI 用 LF。这个设置让你提交时自动转成 LF、检出不转换，仓库里永远是 LF。不设的话，D2 推上 GitHub 后每个文件都会被标成"整个文件改动"，review 时看不见真正的 diff。

**验收**：`git config --global --list` 输出里能看到 `core.autocrlf=input` 和 `init.defaultbranch=main` 两行。

## 第 2 步 · WSL2（需要管理员权限，装完要重启）

**前提检查**（任务管理器 → 性能 → CPU → 看"虚拟化"是否为"已启用"）。若显示"已禁用"，要先进 BIOS 打开 CPU 虚拟化（Intel VT-x / AMD-V），这一步我替不了你。

以**管理员**身份打开 PowerShell（Win+X → 终端(管理员)）：

```powershell
wsl --install --no-distribution
```

`--no-distribution` 的意思是只装 WSL2 内核和虚拟机平台，不下载 Ubuntu。Docker Desktop 会用自己管理的发行版，装 Ubuntu 是白占 2G。

装完**重启电脑**。重启后验证：

```powershell
wsl --version
wsl --status
```

**如果 `wsl --install` 报错**（老版本或策略限制），用 DISM 手动开两个功能，再重启：

```powershell
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

**验收**：`wsl --version` 能打印内核版本（不是"未安装用于 Linux 的 Windows 子系统"）。

## 第 3 步 · Docker Desktop

```powershell
winget install --id Docker.DockerDesktop -e
```

装完**先启动 WSL2 已就绪**（第 2 步验收过），再启动 Docker Desktop。首次启动会拉 WSL 发行版，可能要 2—5 分钟，桌面出现鲸鱼图标、状态显示 Engine running 才算起来。

**验收**（新开一个 PowerShell）：

```powershell
docker --version
docker run --rm hello-world
```

看到 `Hello from Docker!` 才算真装好。`docker --version` 通过只证明装了个客户端，不代表 daemon 在跑——这两行都要过。

**三个坑，按概率排序**：

1. **C 盘不够**。Docker Desktop 本体 1.5G 左右，镜像额外 3—5G。先看空间：`Get-Volume C | Select-Object SizeRemaining`（单位字节，除以 1GB 就是 GB）。不够就把镜像位置改到 D 盘：Settings → Resources → Advanced → Disk image location。
2. **Engine stopped / docker 命令连不上**。九成是 WSL2 没真装好，或 BIOS 虚拟化没开。回第 2 步的验收重跑一遍。
3. **hyper-v 与其它虚拟化软件冲突**（VMware/VirtualBox 旧版）。如果你的 MuMu 模拟器还在用，装完 Docker 可能起不来——真遇到了告诉我，我给你排。

**时间盒**：Docker 是这周唯一可能卡住你的东西。**卡超过 2 小时就停手**，走 B 方案（云环境），别用一整晚换一个容器。

## 第 4 步 · DeepSeek API Key（唯一花钱的一步）

1. 打开 https://platform.deepseek.com/ ，注册/登录（手机号 + 实名）。
2. 充值。**先充 10 元**——按 `deepseek-flash` 的闲时价格（输入 $0.15/百万 token、输出 $0.6/百万 token），一次问答成本约 $0.0001 量级，10 元够你把 W1—W4 跑完。别一次充几百。
3. 侧栏 API keys → 创建 → 复制 `sk-...`（只显示一次）。
4. 在 `W01` 目录建 `.env`（复制 [.env.example](W01/.env.example) 改名），粘贴进去。

```powershell
cd C:\Users\吴晨希\Downloads\Agent开发学习\W01
uv sync                       # 建 .venv 并装依赖（openai SDK）
uv run python first_call.py
```

**预期输出**：一段回答 + `输入/输出 tokens` + `本次成本 $0.0000xx` + `已记账 → calls.jsonl`。

**这一步学到的东西比"跑通"重要**：
- DeepSeek 提供的是 **OpenAI 兼容接口**，所以 `openai` 这个 SDK 改个 `base_url` 就能用。这就是为什么 Skills/框架生态能通用。
- 成本 = 输入 token × 单价 + 输出 token × 单价。**输出比输入贵 4 倍**（$0.6 vs $0.15），所以"让模型少说废话"是省钱的第一手段。
- 忙时是北京时间的上午和下午，价格翻倍；你晚上 9 点写代码，正好是闲时。

**验收**：`W01\calls.jsonl` 出现第 1 行（一行 JSON，含 tokens、latency、usd）。

## 第 5 步 · GitHub（D2 之前完成就行）

如果已有账号，跳过注册；没有就注册一个。然后生成 SSH key：

```powershell
ssh-keygen -t ed25519 -C "2060480728@qq.com"
```

三次回车（不设密码短语也可以），然后：

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
```

把输出的整行贴到 GitHub → Settings → SSH and GPG keys → New SSH key。

**验收**：`ssh -T git@github.com` 返回 `Hi <你的名字>! You've successfully authenticated`。
