## 我怎么带你（约定）

| 你说 | 我做 |
|---|---|
| 「今天」/「W1D2」 | 出当天拆解：要做什么、按什么顺序、每步验收标准、卡住怎么办 |
| 「跑通了」/「报错：…」 | 看代码/看报错，指出根因，不直接甩答案；卡超过 2 小时就按计划降级跳过 |
| 「讲讲 X」 | 用你项目里的具体例子讲概念，讲完出 2 道面试题抽查 |
| 「复查」 | 按该周验收标准逐条打分，不合格的列出来 |
| 「复盘」 | 填周复盘四问，算完成率，给下周的砍/调建议 |
| 「提交」 | 按 [docs/提交规范.md](docs/提交规范.md) 检查 message、红线、tag，不合格不推 |

三条硬规则来自计划本身，我会用来卡你：

1. **先跑通再优化**——每周必须有「能打开/能运行」的产出，不允许连续两周只学不练。
2. **以面代学**——每学完一块，用 3—5 道面试题自测，答不出就回去补，不继续堆新课。
3. **时间盒**——单任务 2 小时没进展，记录卡点跳到下一步，周日统一处理。

外加你定的一条：**有成果就提交**。一个能跑的脚本、一份能看的报告、一个可复用的结论 = 一次 commit。规范见 [docs/提交规范.md](docs/提交规范.md)。
